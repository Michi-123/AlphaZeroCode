AlphaZero 側は **人間の棋譜も定石も一切使わず**、自己対局のみで学習した
モデルです（ルールを教える bootstrap は「勝ち手を打つ / 相手のリーチを止める」
という規則そのものだけで、戦略は含みません）。

人手アルゴリズムの中身:

1. 即勝ち手があれば必ず打つ
2. 相手の即勝ち手を必ず止める（2箇所なら受け無しと評価）
3. 長さ5の窓ごとに 4連=2000点 / 3連=120点 … と形を点数化（重みは人が決定）
4. 石の周囲2マスに候補手を絞り込み（人が決めた枝刈り）
5. 上記の評価関数を α-β 法で先読み（L1=0手, L2=2手, L3=4手）
